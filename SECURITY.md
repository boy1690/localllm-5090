# Security and privacy / 安全與隱私

## English

Do not place credentials, tokens, real user paths, email addresses, private IP addresses, MAC addresses, GUIDs, hostnames, account identifiers, or unreviewed logs in a public issue or pull request. Use GitHub private vulnerability reporting for security or privacy reports.

Model weights, partial downloads, runtime binaries, dependency trees, caches, and build output do not belong in this repository. If a secret enters Git history, deleting the latest copy is not sufficient: revoke the secret first and privately notify the maintainers.

## 繁體中文

不要在公開 Issue 或 PR 放入憑證、token、真實使用者路徑、email、私有 IP、MAC、GUID、hostname、帳號識別碼或未審查 logs。安全或隱私問題請使用 GitHub private vulnerability reporting。

模型權重、partial downloads、runtime binaries、dependency trees、cache 與 build output 不屬於本 repo。若秘密已進入 Git history，只刪除最新檔案不足以撤銷；應先撤銷秘密，再私下通知維護者。
